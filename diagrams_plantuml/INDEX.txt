================================================================================
COMO VISUALIZAR OS DIAGRAMAS
================================================================================

OPÇÃO 1: VS Code (Recomendado)
1. Instale extensão "PlantUML" (Jieliang Chen)
2. Abra ficheiro .puml
3. Pressione Alt + D para preview
4. Clique direito → Export Diagram

OPÇÃO 2: Online
1. Aceda a: https://www.plantuml.com/plantuml/uml/
2. Copie conteúdo do ficheiro .puml
3. Cole na caixa de texto
4. Veja renderização em tempo real
5. Exporte como PNG/SVG/PDF

OPÇÃO 3: Linha de Comando
java -jar plantuml.jar 01_deployment.puml 02_component.puml 09_activity.puml

OPÇÃO 4: Docker
docker run --rm -v $(pwd):/diagrams plantuml/plantuml:latest /diagrams/*.puml
